Review this session itself, not just its output, and be specific:

- **Went well:** approaches, delegations or command sequences worth repeating.
- **Went wrong:** mistakes, dead ends, wasted turns, wrong assumptions, and their root cause.
- **Script candidates:** any multi-step manual sequence done twice, or once but clearly reusable,
  that should become a script or CLI command. Say where it would live.

Run `cavecore which`. If it prints a retro path, read the end of that file, then append a dated
entry: `## <YYYY-MM-DD> - <effort-slug>` followed by the three bullet groups. If there is no retro
path, show the retro to the user instead.

If a finding is a durable rule about how to work (not specific to this task), also save it to
memory, updating an existing memory rather than adding a duplicate.
